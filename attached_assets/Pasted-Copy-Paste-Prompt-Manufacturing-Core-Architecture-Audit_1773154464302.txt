EPOCH MANUFACTURING CORE ARCHITECTURE AUDIT

Objective:
Verify whether the EPOCH ERP contains the minimum manufacturing data structures required for a stable manufacturing system.

This audit must determine if the system supports proper traceability between:

items
bill of materials
production orders
inventory
purchasing

CRITICAL RULES

• READ ONLY
• No file modifications
• No migrations
• No refactoring
• Only inspect and report
• All findings must include file paths and schema snippets

Context

EPOCH supports two production lines:

P1 — Stocks
P2 — Aerospace

Both may manufacture assemblies using BOM structures and purchased materials.

The system currently contains:
inventory_items
multiple BOM implementations
stock_models (saleable products)

We are planning to unify around a single Item Master and must ensure the manufacturing core supports it.
