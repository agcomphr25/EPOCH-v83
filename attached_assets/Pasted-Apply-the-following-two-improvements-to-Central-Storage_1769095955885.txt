- Support nested folders (parent → child)
- Folders are logical (DB-backed), not filesystem-only
- Documents belong to exactly one folder
- Root folder exists by default

- Add a folders table (e.g., media_folders or storage_folders) with:
  - id
  - name
  - parent_id (nullable, self-referencing)
  - created_at / updated_at

- Allow folder-level access rules (initially simple):
  - visible_to_roles (array or join table)

- Allow uploading documents directly into a selected folder
- Allow moving documents between folders
- Show folder tree / hierarchy in the UI

- Existing documents should default to the root folder
- Uploads without a folder selection go to root

Verification:
