CNC (Computer Numerical Control) machines come in several types, each designed for specific manufacturing tasks. Since you're building out CNC routing and dashboards in EPOCH, I’ll break this down in a way that maps cleanly to work centers + routing logic.

🛠️ Main Types of CNC Machines
1. CNC Milling Machines (Most Common)

What they do:
Cut material using rotating tools (end mills, drills, etc.)

Types:

3-axis (e.g., your Haas VF-2) → X, Y, Z
4-axis → adds rotary table
5-axis → complex aerospace parts (huge for composites tooling & metal parts)

Use in your shop:

Rifle stock inletting
Rails before anodize
Drone structural components
Tooling/molds

EPOCH Work Center Example:

CNC - Haas VF2 (3 Axis)
CNC - VF3 (4 Axis Capable)
🔩 2. CNC Lathes (Turning Centers)

What they do:
Rotate the part while tools cut it (opposite of milling)

Best for:

Cylindrical parts
Tubes
Bushings, shafts

In your world:

Compression wrapping (you already use a lathe 👀)
Tube finishing
Mandrel work

EPOCH Work Center:

CNC Lathe - Tube Processing
Lathe - Compression Wrap Station
🔥 3. CNC Routers

What they do:
High-speed cutting of sheet materials

Best for:

Carbon fiber sheets
Foam cores
Panels

In your shop:

Cutting composite sheets before layup
Core shaping

EPOCH Work Center:

CNC Router - Composite Cutting
⚡ 4. CNC Plasma Cutters
4

What they do:
Cut metal using plasma arc

Best for:

Steel/aluminum plate
Fast rough cuts

Not ideal for aerospace precision, but useful for:

Fixtures
Shop tooling
💡 5. CNC Laser Cutters
4

What they do:
High-precision cutting using a laser

Best for:

Thin metals
Precision flat parts

In your environment:

Brackets
Lightweight components
💧 6. CNC Waterjet Machines

What they do:
Cut using high-pressure water + abrasive

Huge advantage:

No heat affected zone (🔥 critical for composites)

Best for:

Carbon fiber
Titanium
Thick aluminum

EPOCH Work Center:

Waterjet - Composite/Metal Cutting
🧠 7. CNC EDM (Electrical Discharge Machining)
4

What they do:
Use electrical sparks to erode material

Best for:

Extremely tight tolerances
Hard metals

Use cases:

Mold cavities
Precision slots

🏭 1. CNC MACHINE MASTER (Work Center Definition)

This is your source of truth for machines → used by routing + scheduling + CNC dashboard.

✅ Required Fields (Your Input — Refined)
cnc_machines
{
  id: uuid

  // Identification
  name: string                 // "Haas VF2"
  cncNumber: string           // "CNC-01", "VF2-01"
  machineType: enum           // MILL, LATHE, ROUTER, WATERJET, LASER, EDM

  // Capability
  axisCount: number           // 3, 4, 5
  axisNotes: string           // "4th axis removable"
  
  // Work Envelope (CRITICAL for planning)
  maxLength: number           // inches
  maxWidth: number
  maxHeight: number
  maxWeight: number           // optional but powerful

  // Material / Process Constraints
  materialRestrictions: string // "No titanium", "Composites only"
  toleranceCapability: number  // e.g. ±0.001

  // Status
  isActive: boolean

  createdAt
  updatedAt
}

⚙️ 2. ROUTING → CNC OPERATIONS STRUCTURE

This is where most systems fail — but you’re about to do it right.

Instead of just “CNC step”, you need:

👉 Operations inside the CNC department

✅ CNC Operations Table
routing_cnc_operations
{
  id: uuid
  partRoutingId: uuid

  operationNumber: number     // 10, 20, 30 (industry standard)
  operationName: string       // "Op10 - Rough Mill"

  machineType: enum           // MILL, LATHE, etc.
  preferredMachineId: uuid    // optional (VF2 vs VF3)

  estimatedSetupTime: number
  estimatedRunTime: number

  notes: string
}
🔧 3. OPERATION DETAILS (Your Requirements — Structured)

Now we attach all the real shop-floor intelligence 👇

✅ CNC Operation Details
routing_cnc_operation_details
{
  id: uuid
  operationId: uuid

  // Program
  programName: string         // "OP10_MAIN.NC"
  programNotes: string

  // Workholding / Setup
  fixtureInstructions: text   // "Install in vise with soft jaws..."
  workOrigin: string          // "G54 top-left corner"
  
  // Tools
  toolList: jsonb             // [{ tool: "T1 - 1/2 EM", holder: "H1" }]
  
  // QC
  qcTolerances: text          // "±0.002 on bore"
  qcCheckpoints: jsonb        // structured checks

  // References
  referenceImages: jsonb      // image URLs
  setupImages: jsonb

  // Knowledge capture
  operatorNotes: text         // "Watch chatter on Op20"
}
