## Release decision

The four confirmed functional blockers are implemented. PR #1651 must remain draft and **DO NOT MERGE** until the replacement disposable PostgreSQL 16.4 workflow is fully green and authenticated browser certification is completed in an explicitly isolated synthetic environment. If no such browser environment is available, that evidence remains pending rather than being fabricated.

The authority boundary is unchanged: the R&D project owns the engineering process; Design Control orchestrates; BOM, routing, traveler, work-instruction, inspection, tooling, document-control, and P2 modules remain authoritative for their own records.
