4) Backend enforcement rules (this is the important part)
Rule 1 — You cannot start work until START tasks are done

When a user tries to mark a step as IN_PROGRESS:

SELECT count(*) FROM traveler_tasks
WHERE traveler_step_id = $stepId
AND task_phase = 'START'
AND required = true
AND status != 'COMPLETED';


If count > 0 → ❌ block

Rule 2 — You cannot sign the step until FINISH tasks are done

When calling:

POST /api/travelers/:travelerId/steps/:stepId/sign


Backend checks:

// all required FINISH tasks completed
AND task_phase = 'FINISH'
AND required = true
AND status = 'COMPLETED'


If any missing → ❌ block signature

Rule 3 — QC Failures override everything

If any task has:

taskType = 'QC' AND value.result = 'FAIL'


Then:

step becomes BLOCKED

signing is disabled

NCR required
