We are investigating two issues:

ISSUE A — Vendor PO Line Items
--------------------------------
When editing a Vendor PO:
- Adding a new line item does not persist correctly
- Line numbers may duplicate (e.g., multiple "Line 2" or "Line 3")
- Line sequencing does not auto-normalize (2,3,4,5…)

We need to determine:
1) Where line numbers are generated
2) Whether numbering is client-side or server-side
3) Whether line numbers are stored in DB or derived at render
4) Whether re-indexing occurs on save
5) Whether optimistic updates override server response
6) Whether multiple saves cause duplication
7) Whether line items are PATCHed or fully replaced
8) Whether DB constraints exist on (po_id, line_number)

--------------------------------

ISSUE B — "Issue PO" Email Disabled
------------------------------------
When Inventory Manager clicks "Issue PO":
- Vendor email SHOULD send
- Copy SHOULD send to Inventory Manager
- Email system was previously active
- It is now disabled or bypassed

We need to determine:
1) Where "Issue PO" action is handled (route)
2) Whether it triggers a status change
3) Whether email logic is conditionally gated
4) Whether a feature flag is disabling email
5) Whether environment variables are required
6) Whether vendor email address is required
7) Whether manager email is passed or derived
8) Whether sendEmail() is commented, wrapped, or bypassed
