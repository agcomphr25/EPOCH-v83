READ-ONLY + IMPLEMENTATION PLAN AUDIT — SIMPLIFY INVENTORY ITEM PROFILE PAGE

Objective
Audit the current Inventory Item Profile implementation and design a simplified structure that separates:

Item Identity

Purchasing Configuration

Manufacturing Usage

The goal is to remove redundant conversion fields and relocate logic so the UI only asks users for true inputs, while derived values (COGS, conversion math, etc.) are calculated automatically.

This audit must identify where the current fields live in the codebase and database, determine which ones are redundant, and produce a safe refactor plan that does not break purchasing, receiving, or MRP logic.

This task includes analysis + refactor plan, but do NOT modify code yet.
