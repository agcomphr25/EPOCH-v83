READ-ONLY ARCHITECTURE AUDIT — INVENTORY ALLOCATION ENGINE

Goal:
Gather the complete technical context required to safely implement the Inventory Allocation Engine for EPOCH.

Do NOT modify any code.
Do NOT insert or update any database records.

This audit must analyze the full inventory system, demand sources, and location architecture.

The objective is to determine how inventory can move through the lifecycle:

Available → Allocated → Committed → Consumed

without breaking existing systems such as:

vendor PO receiving
parts request receiving
cutting table modules
material lot traceability
inventory scans
manual adjustments

--------------------------------
