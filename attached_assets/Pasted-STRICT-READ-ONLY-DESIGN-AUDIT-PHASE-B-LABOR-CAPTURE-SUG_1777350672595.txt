PHASE B TARGET
==================================================

Build a controlled natural-language labor suggestion engine for salaried employees and owners.

Core rule:
AI Suggests
Human Approves
System Audits

“Today I worked on AEVEX helping QC in the morning and had vendor meetings after lunch.”

Then return suggested draft lines such as:

- 4.0 hrs direct labor → likely traveler / charge code / project
- 4.0 hrs indirect → Vendor Management or Meetings
