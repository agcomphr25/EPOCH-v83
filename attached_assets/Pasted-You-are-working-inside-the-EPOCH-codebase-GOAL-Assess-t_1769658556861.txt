You are working inside the EPOCH codebase.

GOAL:
Assess the current state of employee onboarding–related functionality and prepare the system for a new Admin-driven Employee Onboarding Wizard.

This wizard will be used by Admin/HR during an in-person onboarding session with a new employee and must result in:
• A completed employee profile
• A configured user account
• Digitally signed documents stored immutably
• A full audit trail
• Exportable & emailable onboarding PDF bundles

STEP 3 — TARGET FEATURE DEFINITION (NO IMPLEMENTATION YET)

Prepare the system to support:

### A) ADMIN-LAUNCHED ONBOARDING SESSION
• Initiated by Admin/HR only
• Conducted in-person with the employee
• Saved progress allowed (pause and resume later)
• Sequential but flexible (can save one form and proceed to others)

### B) ONBOARDING PATHWAYS
• Configurable onboarding “paths”
• Separate paths for:
  - Full-Time Employees
  - Contractors / 1099
• Admin can define:
  - Intake form(s)
  - Document sequence
  - Required confirmations
  - Follow-up completion rules

### C) DEMOGRAPHIC INTAKE FORM BUILDER
• Admin UI to design intake forms
• Field types:
  - Text, date, dropdown, checkbox
• Fields mapped to employee profile fields
• Reusable across onboarding paths

### D) DOCUMENT SELECTION & SIGNING
• Admin selects signable PDFs from a central storage folder
• Ordered document sequence
• Required digital signature agreement checkbox
• Signature options:
  - Mouse / touch
  - Typed full legal name
• Capture:
  - IP address
  - Timestamp
• Signed documents:
  - Immutable
  - Stored with employee
  - Included in export bundle

### E) DEVICE-CAPTURED ATTACHMENTS
• Optional steps allowing Admin to:
  - Take photos from the device camera
  - Attach images (e.g. driver license, bank info)
• Admin chooses which capture steps are included per onboarding path

### F) USER ACCOUNT SETUP STEP
• Guided Admin UI for:
  - Creating user account
  - Assigning role(s)
  - Assigning permissions
• Account activation tied to onboarding completion

### G) FINALIZATION
• Mark onboarding as complete
• Employee becomes Active
• Ability to:
  - Export onboarding as a single PDF bundle
  - Email the PDF bundle
