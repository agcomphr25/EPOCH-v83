Copy-Paste Audit Prompt

(EPOCH Offline Capability Audit)

You are performing a READ-ONLY ARCHITECTURAL AUDIT of the EPOCH codebase.

GOAL
Determine whether EPOCH can support OFFLINE OPERATION for department operators and what is required to implement it safely.

Offline operation means:

• Department users can continue processing items when internet is down
• Actions are stored locally
• When internet returns, changes sync to the server
• Data conflicts are detected and handled safely
• No production work is lost

This audit is READ-ONLY.
Do NOT modify any files.

• service workers

Analyze whether EPOCH currently supports:

• merge logic

updated_at

Does the system have a way to detect conflicting updates?
