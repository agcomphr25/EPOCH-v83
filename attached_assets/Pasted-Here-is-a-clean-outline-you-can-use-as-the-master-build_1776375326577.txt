6. Key Gates to Enforce

These are the most important system gates:

cannot start work without valid charge code
cannot change charge code without logging it
cannot exceed project labor budget without approval
cannot start traveler without required material traceability
cannot sign regulated steps without proper role and training
cannot close project without closing review
cannot access controlled files without authorization
cannot bypass approvals silently
7. Success Milestones
Milestone 1

EPOCH can create a quote, convert it into a project, create a WAD, and launch work.

Milestone 2

Employees can scan into work, auto-charge the correct code, and all changes are auditable.

Milestone 3

Traveler steps are enforced by material, training, and QC gates.

Milestone 4

Projects close with lessons learned, actions, and reusable risk intelligence.

Milestone 5

System has permission controls, secure vault behavior, and audit logs aligned for CMMC readiness.
