CNC DASHBOARD REQUIRED WORKFLOW

The CNC dashboard must support this full workflow:

A. Job intake
- CNC jobs must come from POs, sales orders, internal work orders, subassembly demand, assembly demand, or rework demand
- Jobs should be tied back to work orders and travelers

B. CNC queue
Each CNC job should show:
- work order number
- PO / SO reference
- part number
- part description
- revision
- quantity
- due date
- priority
- current status
- assigned machine
- assigned programmer
- assigned operator
- linked traveler
- material readiness if available

C. Operation structure
Each CNC job must support multiple operations, for example:
- Op 10
- Op 20
- Op 30
Each operation should support:
- operation number
- operation name
- operation description
- machine
- sequence
- estimated setup time
- estimated cycle/run time
- standard labor time
- status
- notes/tips
- completion signoff

D. Programming and setup package
Each operation should support:
- program name
- program number
- program revision/version
- machine to run on
- datum/work reference point
- work offset notes
- setup notes
- fixture/workholding instructions
- prove-out required yes/no
- setup sheet or document reference if present

E. Tooling
Each operation should support structured tooling data:
- tool number
- tool description
- holder position
- tool holder placement
- size/diameter if used
- offset/setup notes
- life or replacement notes if used
- photo showing correct holder/tool placement

F. Photos and visual instructions
Each operation should support uploaded or linked photos for:
- workholding setup
- datum/reference setup
- part orientation
- tool holder placement
- finished part example
- critical feature reference

G. Machine assignment
The system should support:
- machine name
- machine number
- work center if applicable
- assigned machine per operation or per job depending on design

H. Time tracking
The system should support:
- estimated setup time
- estimated run/cycle time
- actual setup time
- actual run time
- paused/downtime if available
- operator-entered notes

I. QC checkpoints
Each operation should support structured in-process QC checkpoints:
- checkpoint name
- characteristic/spec
- nominal
- tolerance plus/minus if applicable
- inspection method
- inspection frequency
- required yes/no
- pass/fail entry
- measured value entry if numeric
- note entry
- photo required yes/no
- signature required yes/no

J. Workflow progression
The machinist/lead should be able to:
- claim/start a job
- complete setup
- start run
- pause
- complete operation
- put job on QC hold
- sign off operation
- move to next operation
- move to next department or outside process

K. Dashboard usability
The CNC dashboard should function like a control center, not just a static page.
It should include:
- queue/list view
- job detail view
- operation detail view
- setup/program/tooling/QC sections
- actionable controls
