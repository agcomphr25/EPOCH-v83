PHASE 3 — DCAA-SAFE RULES
==================================================

Implement these basic controls:

1. Time entry must be tied to:
- employee
- project
- work_step
- date
- hours

2. Submitted time entries should not be silently editable.
If edited after submission:
- either require unlock/admin flow
- or create a clear audit/history trail
Use the codebase’s existing audit pattern if available.

3. Approved + locked entries must not be editable by normal users.

4. Do NOT auto-fill fake hours.
No silent population of 8-hour days.

5. Preserve created/updated timestamps and actor identity where patterns already exist.
