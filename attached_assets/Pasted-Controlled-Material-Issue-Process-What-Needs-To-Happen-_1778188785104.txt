Controlled Material Issue Process
What Needs To Happen In EPOCH

This is the control layer that prevents:

material going to the wrong project,
unauthorized consumption,
hidden inventory loss,
and untraceable job charging.

Right now EPOCH already has:

travelers,
WAD linkage direction,
queue readiness,
reservations,
lots,
material traceability.

So you are already close structurally.

What’s missing is the hard enforcement engine.

TARGET STATE

Material can ONLY be consumed when ALL conditions are valid.

Think of it like a manufacturing “gate.”

1. REQUIRE RELEASED TRAVELER
Problem

Operators may consume material before production authorization.

Solution

Traveler must be:

status = RELEASED

before:

reserve,
issue,
consume,
or transfer-to-job.
Add Validation Layer

Create centralized service:

validateTravelerIssueEligibility()

Checks:

Check	Required
traveler exists	yes
traveler released	yes
traveler not closed	yes
routing active	yes
project active	yes
2. REQUIRE APPROVED WAD

This is one of the most important DCAA controls.

Problem

Material should not issue against:

unapproved work,
unauthorized builds,
expired jobs,
or engineering-only activity.
Required Rule
WAD.status = APPROVED

before any material issue.

Recommended WAD States
Status
DRAFT
REVIEW
APPROVED
RELEASED
CLOSED
CANCELLED
Enforcement
IF WAD.status != APPROVED
→ block material issue
3. REQUIRE VALID ROUTING STEP

Critical aerospace manufacturing control.

Problem

Material can accidentally issue to:

wrong department,
wrong operation,
wrong phase,
wrong sequence.
Required Validation

Material consumption must occur against:

active traveler step,
current department,
current operation.
Example
Layup material
CANNOT issue during QC step
Add Routing Validation Service
validateRoutingStep()

Checks:

Validation
step active
step not completed
step assigned correctly
step sequence valid
department valid
