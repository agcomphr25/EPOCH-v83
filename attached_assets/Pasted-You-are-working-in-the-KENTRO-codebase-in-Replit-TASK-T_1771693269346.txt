Endpoints:
- GET /api/tournaments/:id/sop
  - If no instance exists, return 404 or { exists:false } (DO NOT auto-create)
- POST /api/tournaments/:id/sop/create
  - MANUAL create: creates instance from latest active template version, creates section/task instances

- PATCH /api/tournaments/:id/sop/tasks/:taskInstanceId

  - Updates assigneeUserId and logs task_reassigned with reason
