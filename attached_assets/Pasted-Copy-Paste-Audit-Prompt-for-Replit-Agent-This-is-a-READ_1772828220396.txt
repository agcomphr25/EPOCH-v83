Goal:
Understand how Vendor vs Source are modeled in inventory items and determine whether the Consolidated Needs page should group by Vendor or Source.

Context:

In the inventory item editor (/inventory/enhanced-mrp) we have these fields:

Vendor:
- the company that manufactures the item

Source:
- where we purchase the item
- examples:
    Vendor = Acme
    Source = Amazon

Sometimes Vendor == Source
Sometimes they differ.

Example:

AG Part: Bolt-123
Vendor: Acme Fasteners
Source: Amazon

The Consolidated Needs page currently groups requests by Vendor.

But purchasing decisions should likely be grouped by Source instead.

We need to audit how the system currently handles this.
