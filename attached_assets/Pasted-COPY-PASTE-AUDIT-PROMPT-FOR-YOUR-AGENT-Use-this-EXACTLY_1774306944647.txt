STEP 3 — DESIGN SIMULATION ENGINE (CORE LOGIC)
--------------------------------

We are simulating WEEK BY WEEK.

INITIAL STATE:
- Load all open orders from DB
- Each order must include:
  - due_date
  - (optional) created_at

SIMULATION LOOP (for each week):

1. ADD NEW ORDERS
   - Create N = ordersPerWeek new simulated orders
   - Assign:
     due_date = current_week_date + assumedLeadTimeDays

2. FULFILL ORDERS (FIFO)
   - Sort all orders by due_date ASC
   - Remove N = shipmentsPerWeek oldest orders

3. AGE REMAINING ORDERS
   - Advance current date by 7 days

4. CALCULATE METRICS
   - past_due_count = count of orders where:
     (current_date - due_date) > 14 days

   - total_backlog = total remaining orders

STORE weekly results
