SECTION 3 — ALLOCATION ENGINE

Audit server/src/services/inventoryAllocationService.ts.

Confirm the presence of the following functions:

allocateInventory()
deallocateInventory()
consumeAllocatedInventory()

For allocateInventory verify:

• inventory_balances row is fetched
• quantity_available is checked
• allocation fails if insufficient inventory
• quantity_allocated increases correctly
• quantity_available recalculates correctly
• inventory_transactions row inserted

For deallocateInventory verify:

• quantity_allocated decreases
• quantity_available recalculates
• transaction logged

For consumeAllocatedInventory verify:

• quantity_allocated decreases
• quantity_on_hand decreases
• quantity_available recalculates
• transaction type = consumption

Also verify:

• database transaction wrapping
• error handling
• type safety
