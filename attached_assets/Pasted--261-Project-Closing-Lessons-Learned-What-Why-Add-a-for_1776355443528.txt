#261 - Project Closing + Lessons Learned

What & Why
Add a formal Project Closing module so projects cannot quietly finish without capturing what happened, what went wrong, what worked, and what must change next time. Right now EPOCH has projects, project steps, travelers, training, and the new WAD backbone, but no true closing record or lessons-learned structure. This ticket adds that missing endcap so the system becomes:

Quote → Project → WAD → Traveler → Time → Closing → Next Project Improvement

Your current schema has no project closing or lessons-learned table yet, so this is a net-new module.

Done looks like
A project_closings table exists and links to projects.id
A project can have one formal closing record
Closing captures:
summary
what went wrong
strengths
opportunities
similarities to prior projects
recommended actions for next time
Supporting child tables exist for:
risks encountered
action items
Storage methods exist to:
create closing
get closing by project
create project risk
list project risks
create closing action
list closing actions
Routes exist to:
create/update a project closing
get project closing by project id
add/list project risks
add/list closing actions
Project closing is additive only; no existing project flow is broken
No frontend pages are required in this ticket
Out of scope
UI page for project closing
mandatory close gate in P2 workflow
analytics dashboards
AI-generated recommendations
backfilling old projects
quote feedback loop automation

Recommended implementation notes
Keep one closing per project

Use a unique constraint on projectId in project_closings. That makes the closeout record the official final review.

Keep risks/actions separate

Do not store risks and actions as raw JSON blobs for this ticket. Use real child tables so they can later drive dashboards, follow-ups, and future quote intelligence.

Keep text fields flexible

For the narrative sections:

summary
whatWentWrong
strengths
opportunities
similaritiesToPreviousProjects
nextProjectRecommendations

Use text fields now. Structured templates can come later.
