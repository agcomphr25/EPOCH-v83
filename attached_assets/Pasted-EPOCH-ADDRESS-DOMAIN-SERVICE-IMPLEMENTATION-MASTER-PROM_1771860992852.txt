PHASE 1 — INTRODUCE ADDRESS DOMAIN MODEL
===========================================

Create:

server/src/domain/address/types.ts

Define:

export type AddressStatus =
  | 'raw'
  | 'standardized'
  | 'validated'
  | 'invalid'
  | 'overridden'

export interface DomainAddress {
  street1: string
  street2?: string
  city: string
  state: string // always 2-letter uppercase
  postalCode: string // normalized 5 or 9 digit
  countryCode: string // ISO-2 (US)
  status: AddressStatus
  validatedAt?: Date
  validationProvider?: 'smarty'
  dpvMatchCode?: string
  overrideReason?: string
}

===========================================
PHASE 2 — BUILD CENTRAL ADDRESS SERVICE
===========================================

Create:

server/src/domain/address/addressService.ts

Implement:

1) normalizeInput(address)
   - trim whitespace
   - uppercase state
   - ISO country conversion
   - strip ZIP non-numeric
   - split 9-digit ZIP to 5+4 if needed

2) validateWithSmarty(address)
   - call Smarty US Street API
   - parse:
       delivery_line_1
       components.city_name
       components.state_abbreviation
       components.zipcode
       components.plus4_code
       metadata.dpv_match_code
   - determine:
       dpv_match_code === 'Y' => validated
       dpv_match_code === 'S' => partial
       else => invalid

3) validateAndNormalize(address)
   - normalize first
   - call Smarty
   - return DomainAddress
   - NEVER silently return original
   - if Smarty fails (network):
       return status = 'invalid'
       include error message
