We have already completed an invoicing audit. Now we are defining the implementation plan for P2 invoicing in EPOCH.

## Locked business rules

Treat these as final requirements:

1. One packing slip = exactly one invoice
2. Invoices are for P2 only
3. When a packing slip becomes SHIPPED, the system should automatically create an invoice in a review state
4. Invoices are NOT auto-sent; they are sent manually
5. We need notification / dashboard visibility for unsent invoices
6. Invoice pricing should default from PO pricing
7. Invoice lines should snapshot pricing at invoice creation time
8. Invoices should be editable before posting, but locked after posting
9. After posting, corrections should happen through:
   - void (if appropriate before send / early internal correction)
   - credit memo
   - replacement shipment / replacement packing slip
   - RMA workflow if physical return is involved
10. Journal entries only will be exported to QuickBooks
11. EPOCH should be the system of record for AR
12. We want full audit traceability:
    Order / PO → Lot → Packing Slip → Invoice → Journal Entry → Payment
