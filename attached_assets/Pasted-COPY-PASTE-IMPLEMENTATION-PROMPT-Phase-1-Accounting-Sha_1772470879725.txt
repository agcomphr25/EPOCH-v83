========================================================
SECTION 4 — ACCOUNTING SERVICE
========================================================

Create new file:

server/src/services/accountingService.ts

Export function:

createOrUpdateFromPayment(paymentRecord, user)

Behavior:

IF paymentRecord.paymentType !== 'wire'
  RETURN (do nothing)

Lookup seeded accounts by accountName.

gross = paymentRecord.paymentAmount
fee = paymentRecord.processingFee || 0
net = gross - fee

IF net < 0 → log error and abort.

Check if journalEntry already exists for referenceType='payment' AND referenceId=paymentRecord.id

IF exists AND status='EXPORTED'
  Log warning and RETURN (no mutation)

IF exists AND status='DRAFT'
  Delete existing journalLines
  Rebuild lines

IF not exists
  Create journalEntry:
    transactionType = 'WIRE_PAYMENT'
    referenceType = 'payment'
    referenceId = paymentRecord.id
    effectiveDate = paymentRecord.paymentDate
    memo = paymentRecord.notes
    status = 'DRAFT'

Create journalLines:

1) Debit Bank Checking = net
2) If fee > 0 → Debit Bank Service Charges = fee
3) Credit Accounts Receivable – Other = gross

Validate:
Sum(debits) === Sum(credits)
If not equal → throw error

Wrap entire function in try/catch.
Log failures but DO NOT block payment route.
