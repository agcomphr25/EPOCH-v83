========================================
PHASE 2 — CREATE LOT ENDPOINT
========================================

Create:

POST /api/p2/lots

Input:
{
  serialIds: string[]
}

Logic:

1. Fetch serial records
2. Validate:
   - all belong to same PO
   - all are finalized

3. Generate lot_number:
   format: LOT-YYYYMMDD-XXXX
   (increment sequence for same day)

4. Insert into p2_lot_numbers:
   - serialized_item_ids = serialIds
   - barcodes = from serial records
   - po_number, customer_id, customer_name
   - lot_type = 'SHIPPING'

5. Return lot_id

========================================
PHASE 3 — CREATE PACKING SLIP
========================================

Create:

POST /api/p2/packing-slips

Input:
{
  lotId: string
}

Logic:

1. Fetch lot
2. Fetch all serials in lot
3. Group by:
   - part_number

4. Build lineItems:
[
  {
    partNumber,
    partName,
    quantity,
    serialNumbers[]
  }
]

5. Fetch customer address from p2_customers

6. Insert into p2_packing_slips:
   - lot_id
   - line_items
   - customer_name
   - customer_address
   - po_number

7. Update p2_lot_numbers.packing_slip_id

8. Return packing_slip_id
