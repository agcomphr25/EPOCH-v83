Domain Truth Inspector UI Cleanup
We are improving the Domain Truth Inspector UI for readability.

This change must NOT modify any workflow logic or database queries.

Only improve how information is displayed.

------------------------------------------------
PART 1 — FIX STATUS DISPLAY
------------------------------------------------

The status field currently renders a serialized React object like:

{
  key: null,
  props: { status: "FINALIZED" }
}

Extract the actual status value.

Logic:

const rawStatus =
  order.status?.props?.status ||
  order.status?.status ||
  order.status ||
  "UNKNOWN";

Then display a human-readable version.

Create helper:

function formatStatus(status) {
  if (!status) return "Unknown";
  return status
    .toLowerCase()
    .replace("_", " ")
    .replace(/\b\w/g, l => l.toUpperCase());
}

Display:

Status: Finalized

Also add a small collapsible section:

Raw Status Value

so debugging is still possible.
