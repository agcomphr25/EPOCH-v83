PROBLEM #1 — PACKING SLIP CONTENTS ARE WRONG
==================================================

Example:
Shipment SWS2505 contains:

- SWS-CAT-SA qty 1
- SWS-AH-LA qty 2

UI correctly shows:
3 stock units

But generated Packing Slip PDF prints:

Contents: SWS-CAT-SA
Sticker #: 1
Quantity: 3

This is operationally incorrect because it prints only the first item description while using total shipment quantity.

This creates receiving confusion, audit risk, and customer mismatch.

--------------------------------------------------

MODEL B — Grouped By Item Type

Example:

SWS2505 | SWS-CAT-SA | [blank] | 1
SWS2505 | SWS-AH-LA | [blank] | 2

Rules:

1. Group shipment items by customer-facing item description

2. Sum quantities per grouped item

3. Leave Sticker # Range column present but BLANK for now

4. Do NOT use:
- first item only
- representative item
- shipment header summary pretending to be line-item truth

5. “Contents” source-of-truth priority must be:

Priority 1:
customer-specific item alias

Priority 2:
sales order line item description

Priority 3:
internal SKU description

Never use:
- random slug fields
- old shorthand values
- inconsistent legacy labels
