DESIGN PRINCIPLES
1. Append-Only
Never:


UPDATE ledger rows


DELETE ledger rows


Only:
INSERT
Corrections are made through:
REVERSAL ENTRY+ NEW CORRECT ENTRY
Exactly like financial accounting.

2. Every Material Movement Creates a Ledger Event
No exceptions.

IMMUTABILITY ENFORCEMENT
Application Layer
Never expose:
PUT /ledger/:idDELETE /ledger/:id
Only:
POST /ledger/reversal

Database Layer
PostgreSQL Trigger
Prevent:


UPDATE


DELETE


Example concept:
CREATE OR REPLACE FUNCTION prevent_ledger_modification()RETURNS trigger AS $$BEGIN  RAISE EXCEPTION 'Ledger entries are immutable';END;$$ LANGUAGE plpgsql;
