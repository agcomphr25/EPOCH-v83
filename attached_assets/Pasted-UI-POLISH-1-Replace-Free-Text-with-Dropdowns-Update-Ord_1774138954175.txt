UI POLISH 1 — Replace Free Text with Dropdowns
Update OrderOverridePage to use controlled dropdowns for status and department.

GOAL:
Remove free-text inputs for critical fields.

---

STEP 1 — FETCH OPTIONS

Add API calls:

GET /api/order-statuses
GET /api/order-departments

---

STEP 2 — STORE IN STATE

const [statuses, setStatuses] = useState([]);
const [departments, setDepartments] = useState([]);

useEffect(() => {
  fetch('/api/order-statuses').then(r => r.json()).then(setStatuses);
  fetch('/api/order-departments').then(r => r.json()).then(setDepartments);
}, []);

---

STEP 3 — REPLACE INPUTS

Replace:

<input onChange={...} />

WITH:

<select onChange={e => handleChange('status', e.target.value)}>
  <option value="">Select status</option>
  {statuses.map(s => (
    <option key={s.id} value={s.name}>{s.name}</option>
  ))}
</select>

<select onChange={e => handleChange('current_department', e.target.value)}>
  <option value="">Select department</option>
  {departments.map(d => (
    <option key={d.id} value={d.name}>{d.name}</option>
  ))}
</select>

---

VERIFY:
- No free text for status or department
