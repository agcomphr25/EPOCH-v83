Station selection isn’t persisted or isn’t included in the start payload

The “most common mismatch” in your architecture (so you can spot it fast)

You said: “timer station initiates the timer and show the model”.

That implies two separate pieces of state:

timer state (running / elapsed / active)

model state (which part/stock model should display)

In EPOCH-style apps, the timer often updates a timer session record, while the model is displayed from:

traveler.partNumber/partName, or

currentStep.departmentName, or

task.instructionPack.timerConfig.model, or

a station.activeModelId

If those don’t line up, you get: “timer starts but model doesn’t change” (or the reverse).

So the agent must tell us: where the model is being read from in the UI.
