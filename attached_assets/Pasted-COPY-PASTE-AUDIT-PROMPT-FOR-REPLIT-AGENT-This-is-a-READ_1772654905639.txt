Problem Description
-------------------
In the Order Entry page of EPOCH, when a user selects a "Barrel Contour" for a Tikka configuration, the UI appears to save it, but the value is NOT persisted. When the order is reloaded or edited later, the Barrel Contour is blank.

Other nearby fields such as:
- Action Inlet
- Bottom Metal
- Barrel Inlet
- Rails
persist correctly.

The objective of this audit is to trace the Barrel Contour field from:

UI selection
→ frontend state
→ API request
→ server route
→ storage layer
→ database schema
→ retrieval query
→ UI rehydration

and determine EXACTLY where the value is lost.
