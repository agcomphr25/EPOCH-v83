PROMPT START

You are conducting a read-only architectural audit of the dashboard system in this codebase.

Your goal is to determine:

How the current dashboard is implemented

What charting and layout systems exist

What components can be reused

What must be built to support a new Production Control Center dashboard

Do NOT modify code.
Only inspect and report.

Run the audit in the phases below.

Search the entire repository for:

Dashboard

dashboard

home

overview

metrics

analytics

• main dashboard pages
• routes that load dashboards
• layout containers
• widget/card components

Component / Page
File Path
Purpose
Route

Search for reusable components such as:

Card

reusable widgets

Phase 4 — Inspect Layout System

Determine how the dashboard layout is currently handled.

Search for:

Grid

Layout

dashboard layout

Determine:

Is the layout static or dynamic?
Are cards draggable?
Can cards be resized?

Report if a grid layout system exists that would support drag-and-drop dashboards.

Search for queries or services used by the dashboard.

Look for:

shipments

Search the codebase for:

time filters

context selectors

MTD

Determine if a global filter system already exists.

Phase 7 — Identify Expand / Modal Patterns

Search for UI patterns supporting:

modal
drawer
expand panel
overlay

These will be needed for:

Swim lane expansion
Widget drilldown

Report reusable components.

Phase 8 — Identify Search and Command Systems

Confirm existing implementation of:

Ctrl+E global search

Determine:

Search component
Search data sources
Search UI implementation
