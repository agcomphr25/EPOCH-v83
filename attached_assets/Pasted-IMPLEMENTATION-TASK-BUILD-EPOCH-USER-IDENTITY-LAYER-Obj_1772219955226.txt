};

----------------------------------------------------
PHASE 3 — CREATE SNAPSHOT RESOLVER
----------------------------------------------------

Implement:

export async function createIdentitySnapshot(userId: number): Promise<IdentitySnapshot>

Behavior:

- Query users table by id
- If user exists:
    firstName = user.firstName ?? ""
    lastName = user.lastName ?? ""
    displayName = `${firstName} ${lastName}`.trim()
- If no user found:
    return:
    {
      userId,
      displayName: "Unknown User",
      firstName: "Unknown",
      lastName: ""
    }

Follow existing Drizzle query patterns already used in the codebase.

DO NOT import route-level logic.
This must remain a pure identity utility.

----------------------------------------------------
PHASE 4 — CREATE FORMATTER FUNCTION
----------------------------------------------------

Implement:

export function formatIdentity(
  snapshot: IdentitySnapshot,
  format: IdentityFormat
): string

Rules:

if format === "full":
    return snapshot.displayName

if format === "first":
    return snapshot.firstName || snapshot.displayName

if format === "initials":
    return:
        first letter of firstName +
        first letter of lastName
    (fallback to first letter of displayName if needed)

Never mutate the snapshot.
This function is pure formatting only.

----------------------------------------------------
PHASE 5 — CREATE INSERT HELPER
----------------------------------------------------

Add helper:

export async function buildIdentityInsertFields(userId: number) {
  const snapshot = await createIdentitySnapshot(userId);

  return {
    userId: snapshot.userId,
    displayName: snapshot.displayName,
  };
}

This helper is for routes that need to store:

<field>UserId
<field>DisplayName

This does NOT perform DB insert.
It just prepares safe identity fields.
