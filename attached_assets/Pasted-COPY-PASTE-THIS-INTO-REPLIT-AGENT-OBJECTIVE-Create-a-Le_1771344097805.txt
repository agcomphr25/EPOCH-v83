🧠 STEP 2 — CREATE FORECAST ENGINE

Create file:

server/services/productionForecastEngine.ts


Export the following functions:

1️⃣ simulateOrderForecast(orderId: number)

Behavior:

Load order

Load routing sequence for that model

Load department_forecast_defaults

Load model multiplier (default 1.0 if missing)

Count active backlog per department (orders currently assigned there and not completed)

Algorithm:

startDate = today (or order.production_start if exists)

For each department in routing order:

    backlogCount = count active orders in that department
    avgDays = department.avg_days
    multiplier = model.multiplier

    backlogDelayDays = backlogCount * avgDays
    processingDays = avgDays * multiplier

    deptStart = startDate + backlogDelayDays
    deptFinish = deptStart + processingDays

    store timeline entry

    startDate = deptFinish


Return:

{
  estimatedShipDate,
  departmentTimeline: [
    {
      department,
      expectedStart,
      expectedFinish
    }
  ]
}

2️⃣ getExpectedDepartment(orderId: number)

Call simulateOrderForecast

Compare current date to timeline

Return:

{
  expectedDepartment,
  expectedStart,
  expectedFinish,
  status: "early" | "on_track" | "late"
}


Late status logic:

If actual department does not match expectedDepartment,
mark as late.

3️⃣ generateDashboardForecast()

Load all active production orders

For each:

Call getExpectedDepartment

Return array:

[
  {
    orderId,
    model,
    actualDepartment,
    expectedDepartment,
    estimatedShipDate,
    status
  }
]
