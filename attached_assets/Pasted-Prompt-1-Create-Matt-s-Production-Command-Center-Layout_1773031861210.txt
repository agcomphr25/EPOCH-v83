Prompt 1 — Create Matt’s Production Command Center Layout

This defines the dashboard layout config.

Writing

You are implementing a new dashboard layout called the Production Command Center (PCC) for EPOCH.

IMPORTANT:
Do NOT modify any existing dashboards.
This should be a new layout.

OBJECTIVE

Create a production-focused dashboard for the production manager (Matt) that provides instant operational awareness.

The layout must use the existing:

DashboardLayout type
DashboardGrid component
Metric widgets
metrics API
