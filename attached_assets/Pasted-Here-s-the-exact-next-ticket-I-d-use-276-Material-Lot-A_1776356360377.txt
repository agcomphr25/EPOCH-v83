#276 — Material Lot Adjustment Route + UI
What & Why

Add a controlled adjustment flow for material lots so inventory can be corrected without using direct database edits or hidden manual workarounds. This covers cycle count corrections, found/lost material, freezer quantity corrections, and supervisor-authorized fixes. The Material Inventory page already supports action-based lot operations like move, split, status change, scrap, issue, return, and history, so adjustment fits naturally into the same action pattern.

Done looks like
A backend route exists for adjusting a lot, such as POST /api/material-lots/:id/adjust
The adjustment supports positive or negative quantity changes
Adjustment requires:
quantity change
reason
performed by
The backend updates all affected records atomically:
material_lots.remainingQty
material_lot_transactions
inventory_transactions
inventory_balances
Negative adjustments are blocked if they would reduce the lot below zero
The Material Inventory page includes an Adjust Lot action in the lot actions dropdown
Clicking it opens a dialog with:
quantity change
reason
performed by
Successful adjustment closes the dialog, invalidates the lots query, and shows a success toast
Errors are shown clearly in a toast
Transaction history reflects the adjustment clearly
Why this is next

Your Material Inventory page already has a mature action pattern with dropdown actions, dialog-driven forms, React Query mutations, and a transaction history dialog. It already supports move, split, change status, scrap, issue, and return, which makes adjustment the next natural lifecycle action to complete inventory control.

Out of scope
Cycle count session workflow
Approval routing or supervisor-only permissions
NCR linkage
Full reconciliation dashboard
Bulk adjustments
